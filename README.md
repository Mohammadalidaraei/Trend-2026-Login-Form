# پلتفرم احراز هویت - Next Platform

یک رابط کاربری مدرن و یکپارچه برای ورود و ثبت‌نام کاربران که با استفاده از PHP، JavaScript و CSS نوشته شده است. این پروژه تمامی کدهای فرانت‌اند و بک‌اند را برای سادگی در نصب و استفاده در یک فایل (`auth.php`) قرار داده است.

## ویژگی‌ها:
- طراحی جذاب و مدرن به سبک **گلس‌مورفیسم (شیشه‌ای)**
- پشتیبانی کامل از زبان فارسی و راست‌چین (RTL) به همراه فونت وزیرمتن
- انیمیشن‌های پس‌زمینه (ذرات شناور و گوی‌های رنگی)
- جابجایی نرم بین فرم ورود و ثبت‌نام (بدون بارگذاری مجدد صفحه)
- اعتبارسنجی فرم‌ها به صورت لحظه‌ای با AJAX
- نوار سنجش قدرت رمز عبور
- امکان مشاهده و مخفی‌سازی رمز عبور
- هشدارها (Toast) زیبا برای ارتباط با کاربر
- طراحی واکنش‌گرا و مناسب برای تمامی نمایشگرها
- شامل افکت‌های سه‌بعدی و شناور (Tilt)

## نحوه استفاده:
کافیست فایل `auth.php` را در سرور یا محیط توسعه خود (مثل XAMPP/WAMP یا استفاده از دستور `php -S localhost:8000`) اجرا کنید.
تمام وابستگی‌های ظاهری و منطقی سیستم در این فایل خلاصه شده است.
